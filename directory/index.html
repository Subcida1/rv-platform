How listings get built

1. Public registries first — the RVTI "Find a Certified Technician" map lists businesses that employ RVTI-certified techs, with the facts a directory needs: name, address, website, phone. Facts aren't copyrightable; a directory built on facts is honest.
2. Text-first cards — no scraped photos, no copied descriptions. Clean, factual, and fast.
3. The business claims the listing — verifies, uploads its own imagery, corrects its hours. What you see after claim is what the business chose.
4. Growth by density — Oregon first, then state by state, so every region we enter is genuinely covered instead of dotted with ghosts.
