# Image credits

Photographs used on this site and where each came from. The build checks this file:
`scripts/verify.py` treats a photo as cleared if its filename stem has a `##` heading
here, so a new third-party photo without an entry fails the gate.

A licence that forbids commercial use or forbids modification is not usable here: the
site is commercial and every image is cropped, which counts as a modification. Every
photograph listed allows both, and the credit is recorded because the licence asks
for it. The card tiles added on 2026-11-15 are recorded here for the same reason.
